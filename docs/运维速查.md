## 二、两个必须先记住的正确认知

**1. 公网版覆盖一切，别再跑去开本地版。**
在家同一个 Wi-Fi 下两台设备互传，**直接开 `https://6.中国` 就行，什么都不用启动**。
服务端按出口 IP 分房，同一条宽带下的设备自动落进同一间房；两台设备在同一局域网时
WebRTC 直连局域网候选地址，**文件不出路由器**，Cloudflare 只做信令。

**2. `start-flashdrop.bat` 只有两种场景才需要：**
① **完全断网**（互联网不通，信令连不出去）；② 连"牵线"都不想交给外部服务器。
断网时靠的是**局域网**（路由器仍在工作，或电脑开移动热点），不是互联网。

## 三、常用命令

```bash
# 部署（必先 export 代理，否则连不上 Cloudflare）
cd D:/workbuddy/flashdrop/cloudflare
export HTTPS_PROXY=http://127.0.0.1:31181 HTTP_PROXY=http://127.0.0.1:31181
npx wrangler deploy

# 查 zone 状态（面板可能是缓存，以 API 为准）
TOK=$(grep -o 'cfoat_[^"]*' ~/.wrangler/config/default.toml)
curl -s --noproxy '*' "https://api.cloudflare.com/client/v4/zones?per_page=50" -H "Authorization: Bearer $TOK"

# 查注册局委派（.cn/.中国/.中國 的 TLD 都是 CNNIC）
nslookup -type=NS 6.xn--fiqz9s 203.119.25.1

# 查四个入口
for h in 6.xn--fiqs8s www.6.xn--fiqs8s 6.xn--fiqz9s www.6.xn--fiqz9s; do
  printf "%-22s " "$h"
  curl -sS --noproxy '*' -m 20 -o /dev/null -w "HTTP %{http_code}\n" "https://$h/"
done
```

## 六、几个"别搞反"的点

- **面板 DNS 页提示缺 `A`/`CNAME`/`MX` → 一条都别补。** Worker 自定义域由
  `custom_domain = true` 在建域时自动建 `type=Worker` 记录；补 MX 反而多开一个投递入口。
- **`type=Worker` 记录在 DNS 页只读、橙云关不掉** —— 设计如此（Worker 没有源站）。
  要解绑去 Workers → 设置 → 域和路由，别在 DNS 页删记录。
- **前端脚本不能写内联** —— 线上 CSP 是 `script-src 'self'`，内联脚本会被静默拦掉。
  本地 `server.js` 已同步加上同一套安全头，避免"本地过线上挂"。
- **本地服务不要加 `Strict-Transport-Security`** —— http 的本地服务会被顶到 https 打不开。
- 本机跑浏览器测试时，**有代理就必须传 `--no-proxy-server`**，否则
  `--host-resolver-rules` 形同虚设（Chrome 把域名交给代理，不自己解析）。
