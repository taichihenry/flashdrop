| 环节 | 怎么查 | 结果 |

| ① 注册局委派 | 直接问 CNNIC 顶级域服务器 `203.119.25.1` / `.26.1` / `.27.1` | ✅ 已返回 `odin` / `tricia` |

| ③ 实际解析 | 公共 DoH 查 A 记录 | ✅ `172.67.172.137` / `104.21.88.44` |

## 四、遗留事项

1. **临时预览域 `flashdrop.midoai.com` —— ✅ 已于 2026-10-05 19:05 解绑移除。**
   从 `wrangler.toml` 删掉该 route 后重新 deploy（版本 `59e64af0`）。验证：
   `workers/domains` 只剩 `6.xn--fiqs8s → flashdrop`；预览域 DNS 记录被自动删除，
   解析返回 **NXDOMAIN**；`https://6.中国/` 仍 **HTTP 200**、`/api/info` 正常、信令实测全过。
   四个测试脚本的默认地址也已从预览域切到 `6.xn--fiqs8s`。
2. **DNS 记录只读属正常**：`6.中国` 是 Worker 自定义域，Cloudflare 自动建的 `type=Worker`
   记录被标记为 read-only，面板上橙云**关不掉**（关了这个站点也会废 —— Worker 只在 CF 边缘执行，
   没有源站）。要解绑走 **Workers → flashdrop → 设置 → 域和路由 → 移除自定义域**。
3. **激活按钮只能人工点**：API 的 `PUT /zones/{id}/activation_check` 用 wrangler OAuth token
   会返回 `9109 Unauthorized`（没有 zone:edit 权限）。
